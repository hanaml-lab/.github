# hanaML

hanaML is an applied AI lab and consultancy. We research how to make agents and small models dependable in real
work, ship the results as open-source code, and build and run AI systems with our clients. More at
[hanaml.com](https://hanaml.com).

## Repositories

| Repository | What it is |
| --- | --- |
| [hana-knowledge](https://github.com/hanaml-lab/hana-knowledge) | Grounded answers over documents: hybrid retrieval with cited character spans, bitemporal graph memory, and claim-level citation checks. |
| [hana-evals](https://github.com/hanaml-lab/hana-evals) | Evaluation of long, multi-stage jobs with model judges calibrated against human labels. |
| [hana-models](https://github.com/hanaml-lab/hana-models) | The model factory: distil a frontier model into a small one, run it on the device, and measure serving cost and latency. |

Each repository's README lists the results it reports and the command that reproduces them. Papers and model cards
are on [hanaml.com/research](https://hanaml.com/research) and [hanaml.com/models](https://hanaml.com/models).
